# Müller Atelier — Simulador de precificação

Calculadora de preços para bordados, kits e presentes do Müller Atelier: cadastro de produtos, montagem de kits, taxas por plataforma (com faixas de preço), mão de obra, margem e divisão dos ganhos.

- Os dados ficam salvos no navegador (localStorage).
- Em **Ajustes e backup** dá para exportar e importar tudo ou só as configurações em JSON.
